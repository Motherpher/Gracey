# Jobbkällor

Karriärhubben börjar med öppna och stabila källor:

- **Platsbanken / Arbetsförmedlingen** – huvudkälla för svenska jobb.
- **Remotive**, **Remote OK** och **We Work Remotely** – kompletterar med distansroller.
- Andra sajter kan läggas till manuellt genom **Jag hittade ett jobb själv**.

Hubben försöker inte logga in, gå runt betalväggar eller hämta information på sätt som en vanlig användare inte får göra.
