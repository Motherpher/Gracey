# Så fungerar karriärhubben

## Hitta jobb
Hubben söker efter roller som ligger nära Grace styrkor och sorterar bort tydliga felträffar.

## Välj jobb
Grace bestämmer själv vad som är intressant. Ingen ansökan skickas automatiskt.

## Sök
För valda jobb skapas ett första underlag. Grace läser, ändrar och skickar själv.

## Följ
Efter ansökan kan processen följas steg för steg så att ingen kontakt, intervju eller sista ansökningsdag tappas bort.
